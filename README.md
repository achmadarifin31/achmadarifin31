### ⚖️ &nbsp;Indonesian Legal Document RAG Ingestion Pipeline

> *GPU-accelerated RAG pipeline for Indonesian legal documents — precision at article level, zero external API calls.*

A production ingestion system for Indonesian statutes and regulations (Peraturan Perundang-undangan). Performs **Pasal-level chunking** with BAB context preservation via **Docling**, with local multilingual embeddings (paraphrase-multilingual-mpnet-base-v2, 768-dim, CUDA) — no external API calls in the hot path.

**Architecture:**

```
📥  Legal PDF Input  →  Cascading Extraction (PyMuPDF → Docling)
       ↓
📐  Pasal-Level Chunker  →  BAB Context Attachment
       ↓
🧠  Local CUDA Embedding  →  768-dim Multilingual Vectors
       ↓
🗄️  Three-Tier Qdrant  →  Hierarchy-Aware Collections
       ↓
🔍  Hybrid Retrieval  →  Dense + Sparse · Authority-Aware
       ↓
🛡️  Graceful Degradation  →  Network / VRAM / Malformed-PDF Handlers
```

### 🏭 &nbsp;Enterprise Document Intelligence Pipeline

> *Production document-parsing and vector storage system — 200K+ docs, Rp 3M total embedding cost, zero duplicate ingestion.*

Built for an enterprise client at PT Node Solusi Teknologi. Ingests 200,000+ historical documents with 50–100 doc/day incremental sync. The system applies a **cascading multi-format extraction strategy** — escalating to costly LLM parsing only when deterministic methods fail — achieving ~Rp 3M (≈ USD 185) total vectorisation cost.

**Key Engineering Decisions:**

```
📥  Multi-Format Ingest  →  PDF, DOC, DOCX, table-heavy files
       ↓
🔀  Cascading Extractor  →  PyMuPDF → Kreuzberg → LLM Fallback
       ↓
🔑  UUID5 Chunk IDs     →  Deterministic, idempotent re-runs
       ↓
🔄  Incremental Sync    →  PostgreSQL diff ↔ Qdrant payloads
       ↓
⚡  Async Semaphore     →  Tuned concurrency (8-core / 16GB)
       ↓
🔒  Permission-Aware    →  Secure retrieval per document ACL
```

**Scale:** `200,000+ documents` &nbsp;|&nbsp; **Sync:** `50–100 docs/day` &nbsp;|&nbsp; **Cost:** `≈ USD 185 total`
